## 📋 Managing Students

### View All Students
The student roster table shows:
- **Name** - Full name (First + Surname)
- **Code** - Their unique 4-digit login code
- **Level** - Current level (starts at 1)
- **XP** - Experience points earned
- **Activities** - Total activities completed

### Edit a Student
1. Find the student in the roster
2. Click the blue "Edit" button
3. Update their First Name and/or Surname
4. Click "Update Student"

⚠️ **Note:** You cannot change the student's code (to maintain login consistency)

### Delete a Student
1. Find the student in the roster
2. Click the red "Delete" button
3. Confirm the deletion

⚠️ **Warning:** This cannot be undone! The student will be permanently removed.

All student data is stored in your browser's localStorage:
- ✅ Persists across page reloads
- ✅ Persists across browser sessions
- ✅ Private to your browser/device
- ⚠️ Clearing browser data will delete all students

**Tip:** If you need to backup your student data, you can export it from the browser's developer tools (localStorage → teacher_steve_students).

## 🆘 Troubleshooting

### "Invalid code" error when student tries to login
- Check that you created the student in the admin panel
- Verify the code matches exactly (4 digits)
- Make sure the student is using their full name as entered

### Students not appearing in leaderboard
- Leaderboard only shows students with XP > 0
- Students need to complete at least one activity to appear
- Refresh the page to see updates

### Can't find admin panel
- Make sure you're logged in as "Steve" with code "2324"
- Scroll down on the homepage - admin panel is at the bottom
- Look for the "👑 Student Management" section

### Data lost after clearing browser
- This is expected behavior
- You'll need to recreate your students
- Consider keeping a backup list of student codes
